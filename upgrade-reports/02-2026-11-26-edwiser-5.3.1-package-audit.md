## Joruri note

1. **Ekhon 4.5-e install korben na.** `requires` field puronoi (2022), tai Moodle install korte dibe, kintu Edwiser-er guide prottek Moodle version-er jonno alada RemUI release dey. Theme 5.3.1 banano hoyeche 5.3-er jonno, tai 5.3 core-er sathe ek sathe install korte hobe.
2. **Order:** Edwiser-er guide bole **theme age**, tarpor baki plugin. CLI upgrade-e shob plugin ek sathe upgrade hoy, tai folder-e copy korar shomoy shob ek sathe rakhlei hobe. Web UI diye install korle theme age din.
3. **Location:** guide-e purono path lekha (`Moodle directory/theme/` ityadi). 5.3-e egulo `public/`-er moddhe jabe.
4. **`local_sitesync`:** Experimental, requires Moodle 4.4, ar Readme khali. Production-er jonno skip korbo.
5. **License:** egulo paid zip, tai public repo-te commit korben na. GitHub repo `MiltonDIU/devlms` public naki private, seta confirm korte hobe.
