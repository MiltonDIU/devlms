## 5. Custom code change (review korben)

### a) `public/login/index.php`: RSA password decrypt port kora
4.5-er core hack (`ENC::` diye shuru password RSA diye decrypt kora) 5.3-er `login/index.php`-e **abar bosano hoyeche**. Logic eki, shudhu key-r path bodleche:
```php
// age:   file_get_contents('../rsa_keys_blc_for_diu/private.pem');
// ekhon: file_get_contents($CFG->root . '/rsa_keys_blc_for_diu/private.pem');
```
`$CFG->root` = project root, ar `$CFG->dirroot` = `public/`. `php -l` diye syntax check kora hoyeche. **Browser-e `ENC::` login test kora baki.**

### b) `public/mod/quiz/accessrule/proctoringlms/rule.php`: 5.3-er quiz API-te port
Plugin-ta age-r `accessrulebase.php` require korto, jeta 5.x-e nei. **Port na korle site-er shob quiz page crash korto.** Ja bodlano hoyeche:
| Age | Ekhon |
|---|---|
| `require_once(.../accessrulebase.php)` | remove kora hoyeche |
| `extends quiz_access_rule_base` | `extends \mod_quiz\local\access_rule_base` |
| `make(quiz $quizobj, ...)` | `make(\mod_quiz\quiz_settings $quizobj, ...)` |
| `mod_quiz_preflight_check_form $quizform` | `\mod_quiz\form\preflight_check_form $quizform` |

Test: 5ta quiz-e `access_manager::load_settings()` OK, `quiz_settings::create()` ar access manager OK, `make()` diye rule toiri OK, `classes/*.php`-er shob file load OK. Baki: `classes/external.php` `external_api` use kore, jeta 5.3-e deprecated, tai debug warning dey kintu kaj kore. **Browser-e webcam ar proctoring flow test kora baki.**

> Note: `quizaccess_proctoringlms` `mod/quiz/accessrule/`-e thaka subplugin, tai amar prothom plugin scan (report 00) eta-ke dhorte pareni. Upgrade-er por "missing from disk" dekhe dhora poreche, tarpor `main` branch theke restore kora hoyeche. `main`-er 487ta plugin folder-er sathe notun tree mile dekha hoyeche. ## 7. ⚠️ Apnake korte hobe (sudo lage, tai ami korte pari ni)

### Nginx (`/etc/nginx/sites-enabled/devlms.local`)
```nginx
server {
    listen 80;
    listen [::]:80;
    server_name devlms.local;

    root /home/milton/Projects/devlms/public;     # ← bodlano
    index index.php index.html;

    location / {
        try_files $uri $uri/ /r.php;               # ← Moodle 5.x router
    }

    location ~ [^/]\.php(/|$) {                    # ← slash arguments (pluginfile.php/...) support
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php8.4-fpm.sock;
    }

    location ~ /\.ht {
        deny all;
    }
}
```
```bash
sudo nginx -t && sudo systemctl reload nginx
```

```php
$CFG->routerconfigured = true;
```
